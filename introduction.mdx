## Core Features

You access Paperguide through a web-based dashboard where you manage projects and documentation. Each project acts as a container for related docs, allowing you to structure information hierarchically. Use folders to group pages logically, and leverage version history to track changes over time.

<Callout kind="info">
  Paperguide supports Markdown and rich text editing, making it easy to add formatted content without complexity.
</Callout>

To begin, navigate to the dashboard and create a new project. Assign a name and description, then add your first page. Paperguide automatically saves drafts and provides preview options to ensure your content looks right before publishing.
