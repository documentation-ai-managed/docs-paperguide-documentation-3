## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration cursors to show active editors.
- Introduced inline commenting for better feedback loops.

## Improvements

- Enhanced search functionality with fuzzy matching for quicker results.
- Optimized page loading speeds by `20%` for larger projects.

## Bug Fixes

- Resolved issue with folder nesting exceeding depth limits.
- Fixed export errors when including embedded media.

</Update>

- Redesigned dashboard for intuitive project overviews.
- Added dark mode support for better accessibility.
