## Creating Pages

You create new pages directly within your project to build out your documentation structure. The editor provides tools for rich content, including text, images, and code snippets. Start by outlining your hierarchy before adding details.

<Steps>
  <Step title="New Page" icon="plus">
    Right-click in the sidebar or use the add button. Enter a title and select a parent folder if needed.
  </Step>
  <Step title="Edit Content" icon="edit">
    Switch to the editor view. Use the toolbar for formatting: bold, lists, headings, and links.
  </Step>
  <Step title="Preview and Publish" icon="eye">
    Click preview to check rendering. Save or publish to make it live for viewers.
  </Step>
</Steps>

<Callout kind="success">
  Pages auto-save every `30 seconds`, preventing data loss during editing sessions.
</Callout>

## Version Control

Paperguide tracks every edit, allowing you to view history and revert changes. Access versions via the page menu to compare diffs or restore previous states.

<ExpandableGroup>
  <Expandable title="How to Revert a Change?" default-open="true">
    Select the page, click history, choose a version, and click restore. This undoes specific edits without affecting others.
  </Expandable>
  <Expandable title="Export Versions">
    Download historical snapshots as Markdown or PDF for backups.
  </Expandable>
</ExpandableGroup>
