## Initial Setup

You start your Paperguide journey by creating an account and setting up your first documentation space. The platform guides you through onboarding with interactive prompts. Follow these steps to get productive quickly.

<Steps>
  <Step title="Sign Up" icon="user">
    Visit the Paperguide website and click the sign-up button. Provide your email and create a secure password. Verify your account via the confirmation email to access the dashboard.
  </Step>
  <Step title="Create Project" icon="folder">
    From the dashboard, select new project. Enter a name like "My Project Docs" and add a brief description. Choose visibility settings: public, private, or team-only.
  </Step>
  <Step title="Add First Page" icon="file-text">
    Inside your project, click add page. Title it "Introduction" and write initial content using the editor. Preview and save to see it in the navigation.
  </Step>
</Steps>

<Callout kind="tip">
  Enable two-factor authentication during setup for added security on your documentation space.
</Callout>

## Best Practices

Organize pages logically from the start, using folders for categories like "API" or "User Guide". Set permissions early to control access. Regularly back up your space via export features.

| Feature | Benefit | Usage |
|---------|---------|--------|
| Folders | Structure content | Drag pages into folders |
| Search | Quick access | Type keywords in search bar |
| Exports | Backup data | Download as ZIP or PDF |

This approach ensures your documentation grows efficiently. With these basics, you build a solid foundation in Paperguide, ready for advanced features like collaboration and API integrations. The platform's design emphasizes simplicity, allowing you to focus on creating valuable content without steep learning curves.
